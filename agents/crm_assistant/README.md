# CRM Assistant

**Phase:** 3 (deferred) · **Plugins used (planned):** `crm`, `email`

## Purpose (planned)

Assists with relationship management once GrowthOS-sourced contacts have enough history to
manage — summarizing relationship state, suggesting next actions beyond simple follow-up
timing (that's Outreach Assistant's narrower job), and syncing with an external CRM plugin
for founders who already run one.

## Why this is deferred

This agent needs real relationship history — actual conversations, actual outcomes, actual
customer status transitions — to have anything useful to assist with. Building it against
`contacts` rows with no real interaction history would mean guessing at what "CRM assistance"
should look like instead of learning it from Phase 1–2 usage. See `ROADMAP.md` §Deferred.
